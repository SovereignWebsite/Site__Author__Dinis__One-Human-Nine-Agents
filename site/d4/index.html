Who it is for

“For anyone with an idea and no team yet.” Leanpub, the book's page: leanpub.com

On 29 October 2026 one person worked with a factory of nine AI agents and gave a talk about nineteen hours after the first commit. The book tells how the factory worked, and how to set up your own, starting the same day.

What you can do after it

  1. Set up your own agent.
  2. Write one page of rules, in your own words.
  3. Write one brief.
  4. Finish one small piece of work on the first day.

A second agent is added only when the first is busy. This is how the Leanpub page describes it. Source: Leanpub.
